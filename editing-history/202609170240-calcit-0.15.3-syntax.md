# Calcit 0.15.3 语法检查 / Calcit 0.15.3 syntax checks

## 中文

- 将模块固定到 Calcit 0.15.3。
- 使用 `surface-latest-v2` 检查完整 Snapshot，并应用编译器能够证明安全的语法优化。

## English

- Pin the module to Calcit 0.15.3.
- Check the full Snapshot with `surface-latest-v2` and apply compiler-proven syntax cleanup.

## 验证 / Verification

- `calcit fix --preset surface-latest-v2 --format edn`
- `calcit --check-only --strict-types`
- `calcit analyze quality`
- `cargo fmt --all -- --check`
- `cargo test`
- `cargo clippy --all-targets -- -D warnings`
