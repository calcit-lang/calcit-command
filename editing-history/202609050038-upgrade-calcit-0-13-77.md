# Calcit 0.13.77 upgrade / 升级 Calcit 0.13.77

## 中文

- 将 `deps.cirru :calcit-version` 从 0.13.64 升级到精确版本 0.13.77。
- 保持 process execution API、Rust 实现、`calcit_native_ffi` 0.1.3 依赖和 C-safe buffer FFI v1 契约不变。
- 使用 0.13.77 CLI 验证 canonical Snapshot、类型检查与真实 dylib 调用，并继续审计预期导出符号及 legacy Rust ABI 符号缺失。
- Calcit 0.13.77 stable Rust 安装问题由 calcit-lang/calcit#660 独立跟踪，本仓库不加入下游 workaround。
- 将 CI 从旧的 `setup-calcit@v1.3.0` 更新到维护中的 `@v1`；旧版本会在 0.13.77 安装后从已移除的位置下载 Caps 并返回 404，而 `@v1` 支持独立 Caps 工具链。

## English

- Upgrade `deps.cirru :calcit-version` from 0.13.64 to the exact 0.13.77 release.
- Preserve the process-execution API, Rust implementation, `calcit_native_ffi` 0.1.3 dependency, and C-safe buffer FFI v1 contract.
- Validate the canonical Snapshot, type checks, and real dylib call with the 0.13.77 CLI while continuing to audit expected exports and the absence of legacy Rust ABI symbols.
- Track the Calcit 0.13.77 stable-Rust installation problem independently in calcit-lang/calcit#660 without adding a downstream workaround.
- Update CI from stale `setup-calcit@v1.3.0` to the maintained `@v1`; the old action downloads Caps from a removed location after installing 0.13.77 and receives 404, while `@v1` supports the independent Caps toolchain.
